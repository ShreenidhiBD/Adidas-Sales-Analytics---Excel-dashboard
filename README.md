# Adidas Sales Analytics Excel Dashboard

## Project Overview
This project is an interactive Excel dashboard developed to analyze Adidas sales data and generate valuable business insights. The dashboard provides a clear understanding of sales performance, profit trends, customer behavior, and regional sales analysis using advanced Excel features and data visualization techniques.

## Objectives
- Analyze overall sales performance
- Identify top-performing products and regions
- Track revenue and profit trends
- Create an interactive and user-friendly dashboard
- Support data-driven business decisions

## Features
- Interactive Dashboard
- Sales & Profit Analysis
- Region-wise Performance Tracking
- Product Category Analysis
- Monthly Sales Trends
- Dynamic Charts and Visualizations
- Slicers and Filters for Better Analysis

## Tools & Technologies Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- Data Cleaning Techniques

## Dataset Information
The dataset contains Adidas sales-related information including:
- Product Name
- Sales Amount
- Profit
- Region
- Units Sold
- Customer Details
- Order Information

## Dashboard Insights
- Top-selling products generated the highest revenue
- Certain regions showed better sales performance
- Monthly sales trends helped identify peak sales periods
- Profit analysis provided better business understanding

## Project Outcome
This project helps visualize complex sales data in a simple and interactive way, making it easier to understand business performance and support strategic decision-making.
